# YZM 411 - Ödev 1

Bu ödevde aynı sahneyi normal ışıkta, gölgede ve masa lambasıyla çekip karşılaştırdım. Piksel değerlerini, RGB ve HSV renk maskelerini, parlaklık ve gama değişimlerini inceledim. Küçültüp geri büyüttüğüm yazıda oluşan detay kaybına da baktım.

Kodlar `main.ipynb` dosyasında, sonuçlar ve yorumlar PDF raporunda. Fotoğraflar `fotograflar/`, çıktı görselleri `outputs/` klasöründe.

## Hedefler

- H1: Görüntünün sayısal yapısını ve farklı ışıklardaki piksel değerlerini incelemek.
- H2: RGB ve HSV renk maskelerini karşılaştırmak.
- H3: Parlaklık ve gama değişimlerinin etkisini görmek.
- H4: Küçültme ve geri büyütmede oluşan detay kaybını incelemek.

## Çalıştırma

1. Gerekli kütüphaneleri yükleyin:

   ```bash
   pip install -r requirements.txt
   ```

2. `main.ipynb` dosyasını Jupyter'da açıp hücreleri sırayla çalıştırın.
